    \question[5] Determine all of the roots of the function $f(x) = 6x^4 - 5x^3 - 4x^2$.

    \begin{solution}
      We find roots via factorization:
      \begin{enumerate}
        \item First we note all terms have a common factor of $x^2$ - so we factor that from the polynomial to get
          \begin{equation}
            x^2(6x^2 - 5x - 4)
          \end{equation}
        \item Since $x^2$ is already factored into linear terms, we need only focus on factoring $6x^2 - 5x - 4$.
          This can be done either by applying the quadratic formula:
          \begin{align}
            \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a} &= \dfrac{5 \pm \sqrt{(-5)^2 - 4 \cdot 6 \cdot (-4)}}{2 \cdot 6} \\
                                                &= \dfrac{5 \pm \sqrt{25 + 96}}{12} \\
                                                &= \dfrac{5 \pm \sqrt{121}}{12} \\
                                                &= \dfrac{5 \pm 11}{12}
          \end{align}
          so our roots are $x = \dfrac{5 + 11}{12} = \dfrac{16}{12} = \dfrac{4}{3}$ and $x = \dfrac{5 - 11}{12} = \dfrac{-6}{12} = -\dfrac{1}{2}$.
          This implies that $(6x^2 - 5x - 4) = 6 \cdot (x - \dfrac{4}{3}) \cdot (x + \dfrac{1}{2}) = (3x - 4)(2x + 1)$.

          Alternatively, we note that factoring as $(ax + b)(cx + d)$ would force
          \begin{enumerate}
            \item $ac = 6$
            \item $bd = -4$
            \item $ad + bc = -5$.
          \end{enumerate}
          so we have $(a,c) = (6,1), (3,2), (-1, -6), (-2, -3)$ and $(b,d) = (4, -1), (2, -2), (1, -4)$.
          The only pair where $ad + bc = -5$ here would be $(a,c) = (3,2)$ and $(b,d) = (-4, 1)$ giving us the above factorization.

        \item We then have that
          \begin{equation}
            f(x) = 6x^2(x - \dfrac{4}{3})(x + \dfrac{1}{2})
          \end{equation}
          from which we can read out the roots.
      \end{enumerate}

      The roots of $f(x)$ are $x = 0, x = \dfrac{4}{3},$ and $x = -\dfrac{1}{2}$.

    \end{solution}
