\section{Type 5 - Challenge Problem}

The \textit{triangle inequality} is a result fundamental to understanding limits. 
It is the statement that, for real numbers $a, b$ we always have that $| a + b | \leq |a| + |b|$.

  Suppose that $f(x)$ and $g(x)$ are continuous at $x = a$, i.e. that for any output error tolerance $\epsilon > 0$
    we can find an input error tolerance $\delta > 0$ so that $|x - a| < \delta$ forces $|f(x) - f(a)| < \epsilon$.

    Show that $f(x) + g(x)$ is continuous at $x = a$, i.e. given some output error tolerance $\epsilon > 0$
    find the right input error tolerance $\delta > 0$ so that $| x - a| < \delta$ forces $|(f(x) + g(x)) - (f(a) + g(a))| < \epsilon$.
